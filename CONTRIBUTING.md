# Contributing to MovePal

1. Start from an assigned GitHub issue.
2. Update local `master`, then create a small feature branch such as `mp-023-webcam-capture`.
3. Commit focused changes with understandable messages.
4. Push the branch and open a draft pull request early.
5. Include the task ID in the PR title and use `Closes #<issue-number>`.
6. Request review from another student. Authors do not approve their own work.
7. Resolve comments and ensure both Windows and Linux CI jobs pass.
8. Merge using squash merge only after approval.
9. Delete the feature branch after merge.

Because this is a private repository in a GitHub Free organization, GitHub cannot enforce protected-branch rules. Direct pushes to `master` are therefore prohibited by the course process and will be reviewed through Git history.
