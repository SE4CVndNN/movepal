# Adult-only collection protocol template

1. Confirm adult status and approved consent before recording.
2. Assign an anonymous identifier; do not use the person's name in filenames.
3. Use a neutral background where possible and remove location metadata.
4. Record only the minimum correct/incorrect examples required by the test matrix.
5. Keep private raw inputs outside Git and CI.
6. Extract landmarks locally to the documented schema.
7. Validate output, provenance, and movement labels.
8. Delete temporary copies and follow retention/withdrawal rules.
9. Review derived fixtures before publication or repository commit.
10. Document sample and environmental limitations.
