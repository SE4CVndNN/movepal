# MovePal Sprint 1 kickoff package

## Instructor-led kickoff — Monday, 13 July 2026

The instructor introduces the MovePal problem, waterfall/agile/Scrum, Product Backlog versus Sprint Backlog, Scrum roles, GitHub issues/branches/PRs/reviews/CI, and the workflow:

```text
Backlog → New → In Progress → In Review → Done
```

Students do not receive separate tasks to rewrite this theory. They begin by reading `docs/student_start_here.md` and carrying out MP-001–MP-003 as practical repository work.

## Sprint Goal

By 29 July 2026, Team B will deliver a documented Flask MovePal prototype with three movement activities, webcam or fallback input, pretrained pose landmarks, rule-based friendly feedback, points/stars, session summary, tests, Windows/Linux CI, privacy/limitations content, and a reliable fallback demonstration. Team A performs final-day manual sanity QA against one frozen release-candidate commit.
