# MovePal Sprint 1 contribution and review report

## Purpose and method

This report records substantive authorship and independent review evidence for
the six active MovePal development members. It uses merged Pull Requests and
GitHub review states inspected on 2026-07-28.

The table is deliberately qualitative. Raw commit, line, or issue counts do not
measure learning, complexity, coordination, investigation, review quality, or
team value. The linked PRs are representative evidence, not a ranking and not
an exhaustive activity export.

## Continuity and interpretation

- Historical commits and reviews remain attributed to their original GitHub
  authors.
- The active-team handoff did not rewrite earlier authorship.
- A merge action alone is not listed as independent review evidence.
- `COMMENTED` review states are described as review participation, not approval.
- Copilot activity is not used as student review evidence.
- Every active development member has both substantive authored work and
  documented review participation on another member's PR.
