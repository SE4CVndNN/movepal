# Manual Pull Request Policy

The private repository is hosted in a GitHub Free organization, so protected-branch enforcement is unavailable. The following policy is mandatory:

- No direct push to `master`.
- One issue per meaningful unit of work.
- One small branch and normally one pull request per implementation task.
- At least one independent review.
- No self-approval.
- Both CI jobs must pass.
- Review conversations must be resolved.
- Squash merge is used.
- The instructor may audit the Git history, pull requests, and review participation.
