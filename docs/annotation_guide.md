# Landmark annotation guide template

For every derived fixture, record:

- anonymous fixture ID
- movement: raise arms, side reach, or knee lift
- requested side where relevant
- expected rule outcome
- correct, near-correct, intentionally incorrect, framing failure, or low-visibility category
- source type: synthetic, licensed sample, or consented adult-derived landmarks
- collection condition such as distance or lighting
- annotator note explaining the expected result
- consent/provenance status

Do not include names, emails, file-system paths, locations, raw video, or background descriptions that can identify a person. A second reviewer checks ambiguous labels before the fixture becomes part of regression tests.
