# MovePal backlog files

`product_backlog.json` is the authoritative machine-readable backlog. It contains all 63 tasks and complete issue bodies.

- `sprint_1.json`: 27 development tasks plus 6 final-day manual QA tasks.
- `qa_backlog.json`: the six external QA sanity checks for 29 July 2026.
- `product_backlog.md`: human-readable complete backlog.
- `sprint_1_plan.md`: assignments, reviewers, estimates, and final-day QA plan.
- `assignment_report.csv`: import/reporting view of Sprint 1 ownership.
- `workload_report.md`: capacity and balance analysis.
- `dependency_report.md`: explicit blocking and coordination relationships.
- `backlog_schema.json`: JSON Schema for structural validation.

The owner bootstrap imports all tasks at initial setup. Sprint 1 and final-day QA are assigned; post-sprint, future, and optional tasks remain unassigned in the Project Backlog.
